# Плагины Звукопада

Плагин — это папка с файлом `plugin.json` и программой на любом языке.
Звукопад запускает программу при первом обращении и общается с ней через stdin/stdout.

Где искать плагины:
- `plugins\` рядом с `zvukopad.exe` — встроенные;
- `%APPDATA%\Zvukopad\plugins\` — ваши. Плагин с тем же `id` заменяет встроенный.

Новые плагины подхватываются при перезапуске программы.

## plugin.json

```json
{
  "id": "piper-tts",
  "name": "Piper (нейросеть)",
  "version": "1.0",
  "description": "Короткое описание для подсказки",
  "type": "tts",
  "protocol": 1,
  "command": "python\\python.exe",
  "args": ["plugin.py"]
}
```

- `id` — латиницей, уникальный.
- `type` — сейчас поддерживается `tts` (синтез речи).
- `command` — путь относительно папки плагина (например, свой портативный Python в `python\`)
  или имя программы из PATH (`powershell.exe`, `python`). Рабочая папка — папка плагина.
- Файл можно сохранять в UTF-8 с BOM или без.

## Протокол (версия 1)

Одна строка JSON — один запрос. Плагин отвечает одной строкой JSON в **stdout**.
Всё остальное (отладка, прогресс, ошибки) — только в **stderr**: оно попадает в лог программы.

Запрос:
```json
{"id": 1, "method": "list_voices", "params": {}}
```
Ответ:
```json
{"id": 1, "result": {"voices": [{"id": "ru-irina", "name": "Ирина", "language": "ru-RU"}]}}
```
Ошибка:
```json
{"id": 1, "error": {"message": "модель не найдена"}}
```

Звукопад передаёт все не-ASCII символы как `\uXXXX`, поэтому кодировка консоли не важна.
Плагину тоже лучше отвечать в ASCII (в Python это `json.dumps` по умолчанию).

### Методы TTS

| Метод | Параметры | Ответ |
|---|---|---|
| `list_voices` | — | `{"voices": [{"id", "name", "language"}]}` |
| `synthesize` | `text`, `voice` (id), `rate` (−10..10), `output` (путь к WAV) | `{"path": "<output>"}` |
| `info` | — | `{"name", "protocol"}` (необязательно) |
| `shutdown` | — | ответ не нужен, просто завершиться |

`synthesize` должен записать WAV-файл по пути `output` и ответить только после этого.
Время ожидания ответа: `list_voices` — 60 с, `synthesize` — 300 с (первый запуск нейросети бывает долгим).

## Пример

`docs/examples/python-tts-example/` — рабочий шаблон на Python (только стандартная библиотека).
Вместо речи он пищит, но протокол реализован полностью. Чтобы попробовать:

1. Установите Python (или положите портативный Python в папку плагина и укажите путь в `command`).
2. Скопируйте папку примера в `%APPDATA%\Zvukopad\plugins\`.
3. Перезапустите Звукопад → «Синтез речи» → движок «Пример плагина на Python».

Чтобы сделать настоящий нейросетевой плагин, замените функцию `synthesize()` в `plugin.py`
на вызов своей модели (Piper, Silero, XTTS…).

Встроенный плагин голосов Windows — `plugins/windows-sapi/` (PowerShell, ~70 строк) — тоже хороший пример.
