ЗВУКОПАД — звуки по горячим клавишам, в наушники и «в микрофон»
=================================================================

Запуск: zvukopad.exe. Устанавливать ничего не нужно.

Ваши звуки лежат в  Документы\Zvukopad\Sounds
Настройки — в       %APPDATA%\Zvukopad
Эту папку с программой можно удалить или заменить новой версией — данные не пропадут.

ЯЗЫК / LANGUAGE
  Язык интерфейса — как в Windows (русский или английский). Сменить: кнопка с глобусом
  справа вверху или Настройки → Язык. English: see README.en.txt.

КАК ГОВОРИТЬ ЗВУКАМИ В DISCORD / SKYPE
1. Установите VB-Cable (бесплатно): https://vb-audio.com/Cable/ — и перезагрузите компьютер.
2. Звукопад → Настройки → «В микрофон»: выберите CABLE Input.
3. Там же включите «Подмешивать мой голос» и выберите свой микрофон.
4. Discord → Настройки → Голос и видео → Устройство ввода: CABLE Output.
5. В Discord выключите шумоподавление и автоматическую чувствительность.
6. Вверху окна Звукопада выберите «Себе и в микрофон».

ГОРЯЧИЕ КЛАВИШИ (схема «Звукопад», меняется в Настройки → Управление)
  Ctrl+Alt+S — остановить все звуки        Ctrl+Alt+P — пауза
  Ctrl+Alt+Space — повторить последний     Ctrl+Alt+X — случайный звук
  Ctrl+Alt+M — себе / в микрофон / оба     Ctrl+Alt+Up/Down — громкость
  Ctrl+Alt+O — оверлей                     Ctrl+Alt+I — оверлей на 3 секунды
  Ctrl+Alt+R — запись                      Ctrl+Alt+E — эффекты
  Ctrl+Alt+B — сохранить «что сейчас было» (если буфер включён на вкладке «Запись»)
  Ctrl+Alt+Q — очередь играть/стоп         Ctrl+Alt+N — следующий в очереди
  Ctrl+Alt+H — выключить/включить клавиши звуков

НОМЕР ЗВУКА НА НУМПАДЕ (как в Soundpad)
  Зажмите Alt, наберите номер цифрами на нумпаде (NumLock включён), отпустите Alt.
  Пока набираете, оверлей показывает подходящие звуки.
  Alt+0 — повторить последний, Alt+точка — отмена.
Клавиши отдельных звуков назначаются на вкладке «Звуки» (можно и кнопки мыши).

СЛУЧАЙНЫЙ ЗВУК ИЗ ТЕГА
  Правый клик по тегу на вкладке «Звуки» → «Назначить клавишу «случайный из тега»».

СИНТЕЗ РЕЧИ БЕЗ ИНТЕРНЕТА (Piper)
  Вкладка «Синтез речи» → «Скачать движок» (22 МБ) → скачайте голос (≈63 МБ) → движок «Piper».
  Скачивается один раз в %LOCALAPPDATA%\Zvukopad\tts\piper. Свои голоса — кнопка «Папка голосов».

Папка plugins — плагины синтеза речи. Не удаляйте её.

При первом запуске Windows может показать «Windows защитила ваш компьютер»:
программа не подписана платным сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
