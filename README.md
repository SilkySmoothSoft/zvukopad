# Звукопад

Саундборд для Windows 10/11: звуки по горячим клавишам — себе в наушники и «в микрофон»
(Discord, Skype, игры), запись звука из браузера или с микрофона, синтез речи с плагинами,
оверлей с подсказками поверх игр.

Версия 1.0.0 (история — [CHANGELOG.md](CHANGELOG.md)). Архитектура рассчитана на развитие (см. «Что дальше»).

## Быстрый старт

| Что сделать | Как |
|---|---|
| Собрать программу | `build.bat` |
| Запустить | `run.bat` (если программа не собрана — сначала соберёт) |
| Упаковать исходники и готовую программу | `pack.bat` → папка `dist` |

**build.bat** — всё сам:
1. Ищет Rust. Если его нет — предлагает поставить в папку проекта `.toolchain`
   (≈600 МБ, без прав администратора, система не меняется; удалить = удалить папку).
2. Если библиотеки ещё не скачаны — выбирает самый быстрый сервер и скачивает.
   Повторные сборки идут без интернета.
3. Компилирует (первый раз — несколько минут, потом секунды).
4. Кладёт готовую программу в `release\Zvukopad\`: `zvukopad.exe`, `plugins\`, `README.txt`.
   Эту папку можно скопировать на любой компьютер с Windows 10/11 — ничего ставить не нужно.

Ошибка компиляции сохраняется в `build_log.txt`.
Сервер для скачивания можно задать вручную: `set ZV_MIRROR=official` (или `rsproxy`, `ustc`, `tuna`), затем `build.bat`.

Используется компилятор `stable-x86_64-pc-windows-gnu` — ему не нужна Visual Studio.

build.bat не привязан к конкретному компьютеру: все пути считаются от папки проекта, Rust берётся
из `.toolchain`, из PATH или ставится заново. Единственное, чего может не оказаться на чужой машине, —
маленькой программы `dlltool.exe` (нужна библиотекам Windows). Если build.bat её не нашёл, он подскажет:
скачать [w64devkit](https://github.com/skeeto/w64devkit/releases) и распаковать в папку проекта
(или в `C:\w64devkit`) — дальше build.bat сам возьмёт оттуда только `dlltool.exe` и `as.exe`.

**Проверка на чистой Windows.** В `.github/workflows/build.yml` — сборка через тот же build.bat
на GitHub Actions при каждом push. Готовую программу можно скачать со страницы запуска (Artifacts).

Батники используют только стандартные программы Windows 10/11: `curl.exe` (скачивание),
`certutil` (проверка контрольной суммы), `robocopy` и `tar` (копирование и zip). PowerShell и
временные скрипты не используются — так антивирусы не принимают сборку за вредоносную программу.

**pack.bat** создаёт:
- `dist\Zvukopad-src-ВЕРСИЯ\` и `.zip` — исходники без мусора (без `target`, `.toolchain`, `release`, логов);
- `dist\Zvukopad-ВЕРСИЯ-win64\` и `.zip` — готовая программа.

## Как говорить звуками в Discord

1. Установите [VB-Cable](https://vb-audio.com/Cable/) (бесплатно) и перезагрузите компьютер.
2. Звукопад → Настройки → «В микрофон» → **CABLE Input**.
3. Там же включите «Подмешивать мой голос» и выберите свой микрофон.
4. Discord → Настройки → Голос и видео → Устройство ввода: **CABLE Output**.
5. В Discord выключите шумоподавление (Krisp) и автоматическую чувствительность.
6. Вверху Звукопада выберите «Себе и в микрофон».

## Возможности

**Звуки**
- Библиотека — обычные файлы в папке, подпапки = категории. wav, mp3, ogg, flac, m4a. Добавление перетаскиванием.
- Поиск (Ctrl+F; ищет и по тегам, и по номеру), фильтр по папкам, **теги** со сворачиваемой панелью
  (фильтр «любой/все», переименование и удаление тега — сами звуки остаются).
- **Цвет** каждого звука — в списке и в оверлее.
- Переименование прямо в списке (двойной клик по названию или F2), удаление в Корзину (🗑, Del, меню).
- **Обрезка** по волне (✂) с прослушиванием фрагмента и плавными краями.
- **Очередь**: звуки по очереди, пауза между ними, по кругу, вперемешку.

**Воспроизведение**
- Себе / в микрофон / оба, раздельная громкость, подмешивание своего микрофона.
- Пауза, повтор последнего, случайный звук, режимы повторного нажатия, выравнивание громкости.
- **Эффекты** для всех звуков: скорость (тон), реверберация, эхо, рация, перегруз, 8 бит, робот; быстрые пресеты.
- **Приглушение (ducking)**: пока вы говорите в микрофон, звуки становятся тише (порог и уровень настраиваются).
- **Случайный из тега**: одна клавиша — случайный звук с выбранным тегом (без повтора подряд).

**Управление**
- Клавиша на каждый звук + 22 общих действия (стоп, пауза, повтор, случайный, режим вывода по кругу,
  громкость, без звука, оверлей, запись, буфер повтора, эффекты, очередь, вкл/выкл клавиш звуков).
- **Автонажатие клавиши рации** (push-to-talk), пока звук идёт «в микрофон» — выключено по умолчанию.
  Это единственное место, где программа создаёт нажатие (SendInput); строгие античиты могут его не любить.
- **Кнопки мыши**: средняя, Mouse4/Mouse5, левая/правая с модификатором.
- **Номер звука на нумпаде, как Numcode в Soundpad**: зажать Alt, набрать номер, отпустить.
  Пока набираете — оверлей показывает подходящие звуки. Alt+0 — повтор, Alt+точка — отмена.
  Номера постоянные и не сдвигаются при удалении других звуков.
- **Пропуск нажатий в игру** (по желанию).
- Готовые схемы: «Звукопад», «Как в Soundpad», «Мышь», «Минимальный» — и любая своя.
- Без перехватчиков клавиатуры и подмены ввода: клавиатура — штатный RegisterHotKey,
  мышь и пропуск нажатий — опрос состояния клавиш.

**Оверлей**
- Режимы: выключен / вкл-выкл клавишей / по клавише на время / всегда; показ при наборе номера и при запуске звука.
- Вид: список или цветные плитки, место на экране (углы, сверху, по центру), ширина, прозрачность, шрифт.
- Пресеты вида («Угол справа», «Во весь экран (плитки)»…) и свои пресеты.

**Редактор паттернов** (вкладка «🥁 Редактор»)
- Дорожки, на которые звуки из библиотеки ставятся перетаскиванием или «кистью» по клеткам сетки
  (такт, 1/4, 1/8, 1/16, 1/32 или без сетки); звуки двигаются мышью и прилипают к сетке.
- Темп (BPM), число тактов и долей, высота (±12 полутонов) и громкость каждого звука, громкость и «выкл» дорожек.
- Игра по кругу без шва (хвосты звуков из конца переходят в начало), правка прямо во время игры.
- «Сохранить как звук» — WAV в папку `Sounds\Паттерны`, дальше это обычный звук с клавишей.
- Паттерны хранятся в `%APPDATA%\Zvukopad\patterns`.

**Запись и таймеры**
- Запись с микрофона или «что звучит» (WASAPI loopback) с выбором устройства.
- **Буфер «что сейчас было»**: пока включён, последние 10–300 секунд держатся в памяти (не на диске);
  по клавише (Ctrl+Alt+B) сохраняются в `Sounds\Повторы`. 30 с ≈ 11 МБ памяти.
- **Таймеры**: записать N минут / сыграть звук / запустить очередь — через заданное время или в заданное время,
  однократно или с повтором. Записи сохраняются сами.

**Прочее**
- Синтез речи: голоса Windows; **Piper** — быстрые нейросетевые голоса без интернета (4 русских голоса,
  скачиваются по кнопке, можно добавить свои); другие нейросети — плагинами (docs/PLUGINS.md).
- Вкладка «Журнал» со всеми событиями и ошибками.
- Переподключение устройств: вынули и вставили наушники — звук вернётся сам.

## Где хранятся данные

В папке программы личных данных нет — её можно удалить или заменить новой версией.

| Что | Где |
|---|---|
| Звуки и записи | `Документы\Zvukopad\Sounds\` (можно сменить в настройках) |
| Настройки, клавиши, громкости звуков | `%APPDATA%\Zvukopad\settings.json`, `library.json` |
| Плагины пользователя | `%APPDATA%\Zvukopad\plugins\` |
| Логи, временные файлы | `%LOCALAPPDATA%\Zvukopad\` |
| Движок и голоса Piper | `%LOCALAPPDATA%\Zvukopad\tts\piper\` |

## Устройство проекта

```
app/                   программа: окно, горячие клавиши, оверлей
  src/main.rs          запуск
  src/player.rs        связь библиотеки со звуковым движком, фоновая загрузка звуков
  src/hotkeys.rs       глобальные горячие клавиши
  src/tts.rs           синтез речи в фоне
  src/piper.rs         встроенный Piper: голоса, запуск piper.exe
  src/download.rs      скачивание движка и голосов (проверка SHA-256, отмена)
  src/ptt.rs           автонажатие клавиши рации
  src/ui/              вкладки интерфейса и оверлей
crates/
  zv-core/             данные: пути, настройки, библиотека (без звука и интерфейса)
  zv-audio/            звуковой движок: устройства, микшер, микрофон, запись, декодирование
  zv-plugins/          плагины: поиск, запуск процессов, протокол, TTS
plugins/windows-sapi/  встроенный плагин: голоса Windows (PowerShell)
docs/                  PLUGINS.md — как писать плагины; пример плагина на Python
```

Принципы:
- **Звук в отдельных потоках.** В звуковом потоке нет блокировок, работы с диском и выделения памяти;
  команды идут через неблокирующие очереди. Окно может тормозить — звук нет.
- **Интерфейс не знает о звуке.** Окно отправляет команды движку и показывает состояние.
  Поэтому можно добавить веб-пульт или управление с телефона, не трогая движок.
- **Плагины — отдельные процессы.** Упавший плагин не роняет программу; писать можно на чём угодно.
- **Настройки совместимы вперёд.** Новые поля получают значения по умолчанию — старые файлы читаются.

Проверка кода (для разработчика): `cargo test`, `cargo clippy`.

## Языки интерфейса

Сейчас есть русский и английский. При первом запуске язык берётся из Windows
(русская Windows — русский, любая другая — английский); дальше его можно сменить кнопкой с глобусом
справа вверху или в Настройки → Язык · Language. Переключается сразу, без перезапуска.

Как устроено (как gettext): в коде пишется русский текст в `tr("…")` или `tf!("… {} …", значение)`,
а `locales/en.json` сопоставляет ему перевод. Английский встроен в программу.

- **Добавили строку в код** — добавьте её перевод в `locales/en.json`. Тест `cargo test` найдёт
  все строки без перевода и перечислит их.
- **Новый язык без пересборки**: скопируйте `locales/en.json` в `de.json` (код языка), переведите значения,
  поменяйте `"_name"` на название языка на нём самом и положите файл в папку `lang` рядом с программой
  или в `%APPDATA%\Zvukopad\lang`. После перезапуска язык появится в списке. Не переведённые строки
  покажутся по-английски.
- Журнал (вкладка «Журнал») пишется по-русски — он для разбора ошибок.

## Иконка

Маскот «Рыжик» — исходник в `assets/icon/` (`rizhik-head.svg` — иконка, `rizhik-full.svg` — во весь рост,
PNG 1024×1024 рядом).

- `app/res/zvukopad.ico` — вшивается в `zvukopad.exe` при сборке (файл `app/build.rs`; отдельный компилятор
  ресурсов вроде windres не нужен — объект с иконкой собирается прямо в build.rs).
- `app/res/icon-256.png` — иконка окна и панели задач.

Своя иконка: сделайте квадратный PNG с прозрачным фоном (лучше 1024×1024) и выполните
`python tools/make_ico.py моя.png` (нужен Pillow) — или положите любой готовый `.ico` в `app/res/zvukopad.ico`.
Для окна замените `app/res/icon-256.png`.

## Как поменять версию

1. В `Cargo.toml` (в корне) поменяйте строку `version = "1.0.0"` в разделе `[workspace.package]`.
   Это единственное место: версию оттуда берут программа (справка, журнал), pack.bat и имена архивов.
2. Запустите `build.bat` — он сам впишет новую версию в `Cargo.lock` (только пакеты программы,
   версии библиотек не меняются).
3. Допишите сверху раздел в `CHANGELOG.md` (и `CHANGELOG.en.md`) — его показывает вкладка «Справка».
4. Выкладка: `publish-github.bat`, затем на GitHub — Release с тегом `vВЕРСИЯ` и zip из `dist`.

Номера — по [семантическому версионированию](https://semver.org/lang/ru/): 1.0.1 — исправления,
1.1.0 — новые возможности, 2.0.0 — что-то несовместимое (например, другой формат настроек).

## Как переименовать программу

Название записано в двух местах:

| Где | Что поменять |
|---|---|
| `crates/zv-core/src/lib.rs` | `APP_NAME` (латиницей: папки данных, журнал) и `APP_TITLE` (как показывается в окне) |
| `app-name.cmd` | `APPNAME`, `APPTITLE`, `EXENAME` — их читают build.bat, run.bat, pack.bat |

Остальной код берёт название из этих мест. По желанию поправьте тексты в `README.md`, `docs/`
и комментариях — на работу они не влияют.

Внимание: от `APP_NAME` зависят папки с данными (`%APPDATA%\Zvukopad` и т.д.). Если его поменять,
программа начнёт с чистыми настройками — старые папки нужно переименовать вручную.
Имена внутренних модулей (`zv-core`, `zv-audio`, …) и `zvukopad` в `app/Cargo.toml` менять не нужно —
пользователь их не видит.
